## Stable 0.2.4

[Download 0.2.4](/download/) or read the
[published release](https://github.com/Ameyanagi/rexafs/releases/tag/v0.2.4).
This release improves startup sizing, empty-workspace actions, editing and folder
scan cancellation. It includes explicit Larch FFT-grid selection and corrections
to legacy iterative AUTOBK behavior. The fixed-penalty default remains unchanged.
Existing format-1 `.rxs` projects remain supported.
