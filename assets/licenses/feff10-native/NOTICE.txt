rexafs includes the FEFF10 native archive distributed with feff10-rs v0.2.3:
https://github.com/Ameyanagi/feff10-rs/releases/tag/v0.2.3
The upstream FEFF10 source revision is 0a4fbd797cf72938f64dda034a438ce009ec6eb7.
Its copyright notices, conditions and disclaimer are in FEFF10-LICENSE.

The macOS prebuilt archives include GCC Fortran and arithmetic runtime objects.
GCC runtime terms and the GCC Runtime Library Exception are included here;
libquadmath uses the GNU Lesser General Public License. Preserve these notices
alongside the Rust wrapper's separate MIT/Apache license files.

Windows packages bundle the feff10-rs v0.2.3 command-line executable
(feff10-windows-x86_64.exe, installed as resources/feff10/feff10-rs.exe) with
the same FEFF10 native archive, plus its MinGW-w64 runtime libraries:
libgcc_s_seh-1.dll, libgfortran-5.dll and libquadmath-0.dll under the GCC
runtime terms above, and libwinpthread-1.dll under the mingw-w64 winpthreads
terms in WINPTHREADS-COPYING. rexafs starts this helper as a separate process.
Source and build instructions for rebuilding/relinking the native archive:
https://github.com/Ameyanagi/feff10-rs/tree/v0.2.3
https://gcc.gnu.org/git/?p=gcc.git
rexafs source: https://github.com/Ameyanagi/rexafs
