# Series workflow validation, 2026-09-16

This record describes unreleased local changes on `feature/complete-analysis`,
after `153aa88`. It does not describe the released 0.2.9 interface. Validation
used the native macOS release build and computer use; Windows and Linux visual
behavior has not been checked in this session.

## Public fixture and screenshots

The source is `scripts/generate-series-metric-example.py`: 513 synthetic spectra
with a varying peak and a deliberately larger signal at frame 258. No experimental
spectra, private projects, source paths or private screenshots are included here.
The two new images in `website/public/screenshots/next/` show the trend editor
and overview. The existing 0.2.9 screenshots retain their historical meaning.

## Observed workflow

- Opening Series displays the heatmap, exact selected spectrum and trend. A
  saved project with several series opens the most recently analyzed series.
- Add trend starts at Maximum, Flat, 0–30 eV relative to each frame's E₀. Changing
  the operation to Mean and the end to 50 updates the preview automatically.
- A reversed interval (0 to −10 eV) clears the preview, explains the error and
  disables Calculate. Restoring a valid end restores the preview.
- Two clicks on the preview update both interval fields. Full spectrum toggles
  between the complete axis and the local range preview without changing the
  calculation definition.
- Calculate all 513 frames completes and returns to the overview. The retained
  Mean trend includes the deliberately larger signal at frame 258.
- Results exports 513 CSV rows, all with Succeeded status. The project was saved
  and reopened, and the retained Mean run was available again.
- Clicking the heatmap selects frame 257; Right advances to 258. The group,
  spectrum, heatmap cursor and trend cursor move together. The white-line
  readout changes from 1.125 to 2.026, matching those synthetic frames. Previously,
  that readout could use a neighboring overview sample; it now uses the exact
  frame cache or remains blank until that frame is ready.
- Advanced retains series editing, presets, recipes and recovery. The inspector
  is hidden during trend setup and results, and returns with the overview.

The overview remains limited to 192 sampled frames. Custom calculations visit
all series members. Saved trends use their retained settings; the overview
representation selector does not silently recalculate them. Saved results from
another series revision cannot attach to a changed frame order.

## Checks

The final full GUI suite passed: 543 tests, zero failures and six ignored tests.
The release build, Rust formatting and patch-whitespace checks passed. The
website check reported zero errors, warnings and hints across 37 files.
The regression tests cover series identities/order, materialized source loading,
unsampled trend peaks, failed-frame gaps and restoring the last analyzed series.

A repeated full test run exposed intermittent checkpoint-lock contention.
A local reproduction showed that closing a locked descriptor can leave its lock
held by an inherited duplicate. Recovery now explicitly unlocks when its owner
finishes, including error paths. A deterministic regression keeps a duplicate
descriptor open and verifies that the next owner can acquire the checkpoint.
