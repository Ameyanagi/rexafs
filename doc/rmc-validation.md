## Multiple-scattering screening investigation

A Cu triangle at [0,0,0], [2.5,0,0], [1.25,2.165063509461,0] Å initially produced
identical spectra with maximum two and four legs. The path records showed that
ReFEFF's default plane-wave screening retained only a two-leg path, with
degeneracy 2 and half-path length approximately 2.5 Å. This was not an adapter
failure to pass the leg-count limit: `paths.inp` contained `nlegxx=4`.

With `CRITERIA 0 0`, the path records also contained a three-leg path of
degeneracy 2 and half-path length approximately 3.75 Å. The final Rust options
therefore expose `[curved-wave, plane-wave]` screening percentages explicitly.
The multiple-scattering test disables these filters for this tiny geometry and
compares its spectrum with the single-scattering result. Default thresholds
remain `[4.0, 2.5]`. Lower thresholds require a runtime and convergence assessment
for larger systems; selecting four legs alone does not establish that any
multiple-scattering contribution survives path selection.
