# Repository instructions

Follow the documentation baseline in [CONTRIBUTING.md](CONTRIBUTING.md) for all
project-authored documents, API comments, docstrings, declarations and examples.

- Use clear, grammatical English and explain unfamiliar terms.
- Explain scientific operations, equations, symbols, units, assumptions and
  parameter effects. Give verified citations and trace implementation claims to
  source code; distinguish rexafs-specific choices from published algorithms.
- Keep public APIs simple. Document recommended defaults and automatic behavior
  where users see completion, signature help and hover documentation.
- Update the relevant guides and editor-visible documentation with API changes.
- Preserve historical data and attribution; label historical/prototype behavior.
